# Voya — такси по Баку

Интерактивная веб-демоверсия будущего iOS-приложения. Работает на React, TypeScript, Vite, Tailwind CSS, Motion и локальном mock API. Реальные GPS, водители и платежи не подключены.

> **Статус:** проект будет дорабатываться. Сейчас это демонстрационный прототип; реальные GPS, водители и платежи пока не подключены.

## Запуск

```bash
pnpm install
pnpm dev
```

Для проверки: `pnpm lint` и `pnpm build`.

## Демо-сценарий

После онбординга введите любой номер и любой шестизначный код. Выберите адрес в Баку, тариф и способ оплаты. Поиск водителя и поездка проходят автоматически; после прибытия водителя нажмите «Я в машине». Данные профиля, поездок, карты и сохранённых мест остаются в `localStorage` браузера.

Скрытая панель `Demo tools` находится в настройках. Она позволяет перейти к ключевым этапам поездки и один раз вызвать ошибку поиска или оплаты. Реальные средства не списываются; номер карты и CVV никуда не отправляются, сохраняются только последние четыре цифры.

## Структура

- `src/services/mockTaxiApi.ts` — mock API и задержки.
- `src/store/useTaxiStore.ts` — единое состояние поездки и локальное хранение.
- `src/components/TaxiMap.tsx` — карта, маршрут и движущиеся машины.
- `src/App.tsx` — экраны и пользовательские сценарии.
- `src/services/webmcp.ts` — необязательные инструменты для браузеров с WebMCP.

Описание созданных изображений находится в [ASSETS.md](ASSETS.md).
